# 视频逐帧检测报告（video_report）

- 运行时间：2026-11-24（Asia/Shanghai）
- 输入视频：`inputs/pigtrack0001.mp4`（1280×800，10 fps，149 帧，约 14.9 s，13.98 MB）
- 模型/权重：`yolov8_s` / `third_party/PigBench/detection/data/pretrained_weights/yolov8_pigs/yolov8_s.pth`
- 设备：CPU（无 NVIDIA GPU）
- 阈值：`--conf 0.4`（与图片推理一致）；`--stride 1`（每帧都检测）
- 实际命令：

```powershell
.\.venv\Scripts\python.exe video_predict.py --video inputs\pigtrack0001.mp4 `
    --weights yolov8_s --conf 0.4 --stride 1
```

> 本报告只描述逐帧检测结果，**不是跟踪**：没有跨帧 ID，计数是每帧独立检测出来的，
> 帧间会跳动。没有标注真值，因此不计算 mAP / 准确率等精度指标。

## 3. 逐帧计数曲线

统计来自 `results/video_counts.csv`（149 行，只含实际检测帧）：

| 指标 | 数值 |
| --- | --- |
| 平均计数 | 12.95 |
| 最小计数 | 11（共 8 帧） |
| 最大计数 | 15（共 2 帧：第 29、131 帧） |
| 计数分布 | 11:8 帧，12:33 帧，13:68 帧，14:38 帧，15:2 帧 |
| 计数为 0 的帧 | 0 帧 |
| 最大帧间跳变 | 2 头 |
| 帧间跳变 ≥3 头 | 无 |

**异常排查结论：**

- 没有出现“长时间全是 0”的片段；全程计数在 11–15 之间。
- 没有出现“数量突然翻倍”的帧或片段。
- 低值段（11 头）集中在第 84–98 帧附近，属于猪只挤在一起、互相遮挡时的正常波动；
  15 头只出现在第 29、131 帧两帧，随后回到 13–14，未见持续异常。
- 计数曲线是逐帧独立检测的结果，**±1~2 头的跳动是预期现象，不是跟踪轨迹的中断**。

## 5. 目测观察与已知问题

- 整体：猪只轮廓清晰时框贴合较好；栏杆、料槽、强反光区域附近的框会有偏移。
- 画面右下角的猪群密集区（第 74、148 帧可见）存在多个框相互重叠，个别低分框
  （如 0.34、0.36）可能是重复框或只框到局部，**会让该帧计数略偏高**；没有真值，无法定量确认。
- 画面左侧有黑色遮挡条和反光，未见误检成猪的框。
- 逐帧检测没有跨帧关联：同一头猪在相邻帧的框可能左右抖动，计数也会 ±1~2 跳动；
  本功能**不提供个体 ID、不提供轨迹、不能回答“同一头猪”的问题**。
- 视频里猪只数量在 11–15 之间波动，与画面中猪只相互遮挡/分开的目测情况一致。
